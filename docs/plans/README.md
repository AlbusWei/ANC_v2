# Plans SSOT (Single Source of Truth)

本目录当前仅以下两份文档具有**权威性**：

1. `docs/plans/SSOT-design.md`
2. `docs/plans/SSOT-implementation.md`

除上述两份外，其余历史计划均已归档到 `docs/plans/archive/`，仅供追溯，不再作为执行依据。

## 使用规则

- 任何新需求先更新 `SSOT-design.md`（设计决策）。
- 设计确认后再更新 `SSOT-implementation.md`（执行任务与验收口径）。
- 不再新增平行“同主题 implementation plan”；如需补充，直接在 SSOT 内增量更新并记录变更。
