# 员工请假审批测试计划

## 关键路径
- KP-01 提交申请成功：员工提交开始/结束时间、原因、附件，返回申请ID，状态=Pending。
- KP-02 审批通过：直属主管对本团队申请执行Approve并附理由，状态=Approved。
- KP-03 审批拒绝：直属主管对本团队申请执行Reject并附理由，状态=Rejected。
- KP-04 审计闭环：提交、审批、状态变化三类事件均可在审计日志中检索并关联request_id。

## 异常路径
- EP-01 员工越权读取：员工A读取员工B申请，期望403，且记录拒绝审计事件。
- EP-02 主管跨团队审批：主管X审批非本团队申请，期望403，状态不变。
- EP-03 审批无理由：主管审批请求缺少理由，期望400/422，状态不变并有错误日志。
- EP-04 限流触发：同一身份在窗口期内高频调用提交/查询接口，期望429与Retry-After，并记录限流事件。
- EP-05 审计缺失防逃逸：模拟日志写入失败时，流程返回失败并保留失败证据，不允许静默成功。

## 失败判定
- 缺失权限控制能力或出现越权成功样例 => FAIL。
- 缺失审计核心事件（提交/审批/状态变化）或日志字段不完整 => FAIL。
- 限流未生效、可稳定绕过或无可追溯限流证据 => FAIL。
- 未提供最小可执行测试证据（关键路径+异常路径）或证据不可复现 => FAIL。
- 任一P0风险未覆盖、结果不确定或相互矛盾 => FAIL。
