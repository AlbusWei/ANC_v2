# Recursive Process Standard (P1-P6)

> 版本: v0.2.0 | 性质: 方法论脚手架

## 1. 目的

P1-P6 是流程架构设计的 top-down 工具，不替代 L0-L5 系统分层。

## 2. 层级定义

1. `P1` 企业价值链流程
2. `P2` 领域价值流流程
3. `P3` 产品生命周期流程
4. `P4` 端到端交付流程
5. `P5` 子流程与模式流程
6. `P6` 原子流程

## 3. 递归规则

1. 任一流程节点可组合子流程。
2. 允许同层级流程引用与组合。
3. 必须显式声明终止条件。
4. BPM 必须采用栈帧式实例隔离。

## 4. 父子流程回填规则

1. 子流程只输出契约化结果，不直接改写父流程运行态。
2. 父流程通过 `output_ref` 与 `child_instance_id` 回填。
3. 任一回填失败必须触发 Fail-Closed。

## 5. 设计检查单

- [ ] 每个 P 层至少一个流程样板
- [ ] P4 流程可追溯到 P6 原子流程
- [ ] 同层组合关系可解析
- [ ] 无无终止条件循环
