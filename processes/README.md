# Processes Directory

## Layout

1. `/Users/albus/MyProjects/ANC_v2/processes/template/`：流程模板资产。
2. `/Users/albus/MyProjects/ANC_v2/processes/development-process/`：真实示例流程（Phase 0.5 最简版）。

## Rule

- 每个 process 目录至少包含 `SKILL.md` 与 `process.json`。
- `template` 目录不注册到 registry。
- 非模板流程必须在 `process_registry.json` 可发现。
